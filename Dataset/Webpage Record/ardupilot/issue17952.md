# Basic Information:
### Title: Copter-4.1: terrain following in Auto may hit terrain (or fly too high) if terrain is too steep
### Issue status: Closed
### Author: rmackay9
### Issue open time: Jul 07, 2021
# Report
### Report author: rmackay9
### Report Time: Jul 07, 2021
### Report Content:
Copter-4.1's  Auto modes accepts position targets with the altitude specified as an alt-above-terrain.  The vehicle may not maintain the target terrain altitude if the terrain is too steep.  The maximum steepness is really the ratio of WPNAV_SPEED to WPNAV_SPEED_UP or DN.  Put another way, the vehicle will not slow down horizontally in order to maintain the target alt-above-terrain.  
The result is that the vehicle climbs to a very high altitude above the terrain and then finally descends to the desired 20m-above-terrain when it reaches the destination.  In test it both starts and ends at about 20m-above-terrain so it should maintain this 20m-above-terrain for the entire journey    
If the above test is repeated after setting WPNAV_SPEED = 200 (2m/s) then the vehicle will correctly maintain a 20m-above-terrain  
PR \\\#17539 resolved the issue for Guided mode. which could be reproduced like this:  
- start SITL in Karuizawa (a mountainous region of Japan) ""../Tools/autotest/sim_vehicle.py --map --console --speedup=10"  
- param set WPNAV_SPEED 1000 (set horizontal speed in Guided+Auto to 10m/s)  
- graph TERRAIN_REPORT.current_height (to produce a real-time graph of the alt-above-terrain)  
- GUIDED  
- arm throttle  
- takeoff 20  
- module load message  
- message SET_POSITION_TARGET_GLOBAL_INT 0 1 0 11 3576 363215670  1386596701 20 0 0 0 0 0 0 0 0
