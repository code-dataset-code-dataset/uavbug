# Report
### Report author: rmackay9
### Report Time: Jun 04, 2019
### Report Content:
In Copter and Rover the vehicle should stop at the circular fence in Loiter (for Copter) and Acro (for Rovers).  This works if AVOID_BEHAVE = 0 (slide) but does not seem to work when AVOID_BEHAVE = 1 (Stop).  Stopping at the polygon fence does appear to work for Copter.  
This can be easily reproduced in SITL:  
- paramset FENCE_ENABLE 1  
- paramset FENCE_TYPE 1  
- param set FENCE_RADIUS 50  
- param set AVOID_ENABLE 1  
- param set AVOID_BEHAVE 1  
Arm the vehicle in Loiter (for Copter) or Acro (for Rover) and drive the vehicle towards the fence.  The vehicle will slow but after some time it will breach the fence and the failsafe will trigger the vehicle to switch to RTL mode.
