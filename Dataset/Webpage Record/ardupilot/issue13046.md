# Report
### Report author: rmackay9
### Report Time: Dec 13, 2019
### Report Content:
Copter's initial climb in RTL goes very high if Rally points are used.  It can be recreated by doing this:  
- set RALLY_INCL_HOME 0 (to make the vehicle fly to the rally point instead of going home)  
- set RALLY_LIMIT_KM 2 (to allow a rally point to be placed more than 300m away)  
- create a rally point with altitude set to the location's terrain altitude  
- LOITER, arm throttle, rc 3 1100  
- RTL  
The vehicle will climb very high before moving to the point  
It's possible that I simply don't understand how to setup the points but my understanding was that they have "absolutely altitudes" but perhaps there is a subtle switch between relative-to-home and absolute at some point.  
There's some comments here in AP_Rally that look very out-of-date but may be related.

### Comment Content:
After discussion with @peterbarker it seems that the issue is that Rally point altitudes are relative to home.  This is mentioned on the wiki page: https://ardupilot.org/copter/docs/common-rally-points.html  
So basically I wasn't setting the rally point altitude correctly so closing!
