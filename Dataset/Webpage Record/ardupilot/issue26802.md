### Title: AP_Mission: Jump send text to user is not displayed for endless jumps
### Issue status: Closed

### Issue open time: Apr 15, 2024
# Report
### Report author: rmackay9
### Report Time: Apr 15, 2024
### Report Content:
If a DO_JUMP mission item has a non-zero "Repeat" field then a helpful text is sent to the user.  
If the command has a "Repeat"field value of -1 then the text is not displayed.  
This issue can be replicated in SITL by doing the following:  
1. Start SITL with a Copter (although the bug applies to all vehicles)  
2. add a square mission with a DO_JUMP command as shown below.  Start with a Jump "Repeat" of 6    
3. Fly the mission and note the Text output to the user as each Jump command is passed    
4. Change the DO_JUMP command's "Repeat" field to -1    
5. Fly the mission again and note that no text is output to the user as the Jump commands are passed    
At first glance the issue might appear to be in the AP_Mission::start_command() function which is where the text is sent but I suspect that the issue is more complicated than this.  I'm actually surprised that start_command() is called at all for DO_JUMP commands.  I thought that they should be completely transparent to the vehicle code.  
This issue was first reported here in the Copter-4.5 forums.
