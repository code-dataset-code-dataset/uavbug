# Report
### Report author: rmackay9
### Report Time: Aug 24, 2022
### Report Content:
AP_Mount attempts to calculate the angle to an invalid location (0,0,0) if the user directly sets the mode to 4 (GPS_POINT).  
The issue can be recreated in SITL (and only SITL) by doing the follwing:  
- param set MNT_TYPE 1 (and reboot SITL)  
- long MAV_CMD_DO_MOUNT_CONTROL 0 0 0 0 0 0 4 <-- changes mount to GPS_POINT mode  
This isn't really very serious because it won't happen on a real vehicle.  I have a fix coming shortly
