### Report Content:
During testing of a large Ackerman steering Rover we found the throttle would sometimes spike to nearly 100% when the throttle was first raised in Acro mode if the vehicle had previously been driving in Auto but the mission was interrupted.  
These steps reproduce a similar issue in SITL although note that the throttle spikes in Acro mode even without the throttle being raised:  
- set speed controller parameters so that the vehicle requires a lot of I-term:    
- param set CRUISE_THROTTLE 100    
- param set CRUISE_SPEED 5    
- param set ATC_SPEED_P 0    
- graph VFR_HUD.throttle (to make output throttle visible)  
- make speed controller I-term visible    
- param set GCS_PID_MASK 2 (so that PID outputs are sent to GCS)    
- graph PID_TUNING.I (to make I-term visible)    
- create a simple auto mission (using "wp editor") with a long straight segment  
- arm and switch to Auto mode  
- once the I-term has risen, change to Manual mode  
- change into Acro mode and look for a throttle spike and/or I-term not being reset to 0  
I think we probably need to reset the speed controller's I-term to zero if it hasn't been used recently (within the last second or so).
