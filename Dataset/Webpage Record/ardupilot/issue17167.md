Bug report  
Issue details    
I found a weird issue where EK3_DRAG_BCOEF_Y are reset to the default.  
The reproduce procedure:  
1. run STIL  
2. param set EK3_DRAG_BCOEF_Y 50  
3. reboot SITL  
4. param show EK3_DRAG_BCOEF_Y    
displayed "EK3_DRAG_BCOEF_Y 0.000000"  
What I confirmed:  
1. delete eeprom.bin    
nothing change  
2. confirmed other EK3_DRAG_* params    
other parameters hold the value after rebooting  
3. changed the index from 3 to 7    
before    
AP_GROUPINFO("DRAG_BCOEF_Y", 3, NavEKF3, _ballisticCoef_y, 0.0f),    
after    
AP_GROUPINFO("DRAG_BCOEF_Y", 7, NavEKF3, _ballisticCoef_y, 0.0f),    
DRAG_BCOEF_Y holds the value after rebooting  
```cpp   
 /*ardupilot/libraries/AP_NavEKF3/AP_NavEKF3.cppLine 679  
      inc83774a*/AP_GROUPINFO ( " DRAG_BCOEF_Y " , 3 , NavEKF3, _ballisticCoef_y, 0 . 0f ),  
```  
1. changed the index of DRAG_M_NSE from 4 to 3    
DRAG_M_NSE are reset to the default  
```cpp   
 /*ardupilot/libraries/AP_NavEKF3/AP_NavEKF3.cppLine 688  
      inc83774a*/AP_GROUPINFO ( " DRAG_M_NSE " , 4 , NavEKF3, _dragObsNoise, 0 . 5f ),  
```  
1. reproduced this issue with KakuteF7mini
