### Report Content:
I've found that I can cause the autopilot (a cube black) to reboot fairly easily using MAVFTP from Mission Planner.  The steps to recreate the issue are:  
1. flash master onto the Cube Black (I was using "ArduCopter V4.0.3-dev 0cf747c")  
2. restore all parameters to their defaults  
3. open Mission Planner and press Ctrl-X to connect using MAVFTP  
4. attempt to open the APM directory  
At this point the connection to the autopilot is lost.  MP goes on to print a nasty error message but this is another matter.
