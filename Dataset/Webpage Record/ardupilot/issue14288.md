# Basic Information:
### Title: EKF3: "still initialising" or "EKF attitude is bad" if compass disabled while using external nav
### Issue status: Closed
### Author: rmackay9
### Issue open time: May 05, 2020
# Report
### Report author: rmackay9
### Report Time: May 05, 2020
### Report Content:
If the EKF3 is using "external navigation" for yaw, the vehicle cannot be armed because the "EKF3 still initailising" pre-arm check is triggered.  
To reproduce the issue in SITL:  
- param set EK2_ENABLE 0  
- param set EK3_ENABLE 1  
- param fetch  
- param set EK3_GPS_TYPE 3  
- param set EK3_MAG_CAL 5 ("Use external yaw sensor")  
- param set AHRS_EKF_TYPE 3  
- param set VISO_TYPE 1  
- param set COMPASS_USE 0  
- param set COMPASS_USE2 0  
- param set COMPASS_US3 0  
- param set SERIAL3_PROTOCOL 1  
Reboot SITL and start with vicon enabled:  
- ../Tools/autotest/sim_vehicle.py --map --console -A "--uartB=sim:vicon:"  
Right-mouse-click on the MAVProxy map and select, "Set Origin (with height)".  At this point normally the vehicle would appear on the map but it won't.  
The vehicle will appear on the map if the compass is enabled as the EKF's yaw source:  
- param set COMPASS_USE 1  
- param set EK3_MAG_CAL 3 ("After first climb yaw reset")
