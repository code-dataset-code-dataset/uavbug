# Report
### Report author: rmackay9
### Report Time: May 15, 2023
### Report Content:
During Auto mode with WP_YAW_BEHAVIOR=0 the vehicle's heading should not change but in fact it does very slightly especially as the vehicle rounds a waypoint.  This can be reproduced in SITL by:  
- param set WP_YAW_BEHAVIOR = 0  
- param set AUTO_OPTIONS = 7 (1:Allow Arming, 2:Allow Takeoff Without Raising Throttle, 4:Ignores pilot yaw)    
- input a square mission, arm and fly the mission    
- download the logs and check the ATT.DesYaw and note that it changes during the flight    
I've discussed this with @lthall and he has an enhancement included within the Copter ship landing feature that should resolve this.
