### Report author: rmackay9
### Report Time: Oct 20, 2021
### Report Content:
It seems that Rover-4.2.0-DEV allows arming in Manual mode during RC failsafe even when ARMING_CHECK = 1.  
This can be reproduced in SITL by doing the following:  
- cd Rover  
- Tools/autotest/sim_vehicle.py --map --console  
- param set SIM_RC_FAIL 1  
- arm throttle  
This is apparently not a safety issue because Mode::get_pilot_input() checks the failsafe status and returns zero throttle and steering.  Still, we shouldn't allow arming in Manual with no RC.
