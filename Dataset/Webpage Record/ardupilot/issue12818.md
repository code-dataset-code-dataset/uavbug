# Basic Information:
### Title: Copter: Auto can become stuck on takeoff command if altitude error is large (?)
### Issue status: Closed
### Author: rmackay9
### Issue open time: Nov 11, 2019
# Report
### Report author: rmackay9
### Report Time: Nov 11, 2019
### Report Content:
An auto mode may become stuck on the takeoff command if these steps are performed in SITL:  
- enable the rangefinder with this parameter file: https://github.com/ArduPilot/ardupilot/blob/master/Tools/autotest/default_params/copter-rangefinder.parm.  I.e. param load ../Tools/autotest/default_params/copter-rangefinder.parm and then reboot SITL  
- upload a mission like this:    
- takeoff to 5m    
- waypoint to some point (does not matter where)    
- return-to-launch (probably also not relevant)    
- arm the vehicle in Loiter  
- rc 3 2000 (a rapid takeoff seems to be necessary)  
- switch to auto when the vehicle reaches about 10m  
It seems the vehicle is stuck on the takeoff command (I added some extra logging in the 1hz loop to see which command it was on).  It seems like AC_WPNav's reached_destination() is perhaps not true.
