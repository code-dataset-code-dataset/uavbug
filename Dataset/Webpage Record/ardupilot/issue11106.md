# Basic Information:
### Title: Copter: setting GCS_PID_MASK = 8 affects takeoff in SITL (at least)
### Issue status: Closed
### Author: rmackay9
### Issue open time: Apr 13, 2019
# Report
### Report author: rmackay9
### Report Time: Apr 13, 2019
### Report Content:
It seems that sending the AC_PosController's Z-axis acceleration PID info to the ground station via mavlink affects the vehicle's ability to takeoff in SITL (at least).  I'm not sure if this is the case on actual vehicles as well.  To recreate the problem in SITL:  
- startup a default quadcopter in SITL using, "sim_vehicle --map --console"  
- param set GCS_PID_MASK 8 (to enable sending of the PID objects FF, P, I, D, etc to the GCS)  
- Loiter  
- arm throttle  
- rc 3 2000 (to take-off)  
The vehicle will fail to takeoff because one motor goes very.
