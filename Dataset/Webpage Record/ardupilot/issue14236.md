# Report
### Report author: rmackay9
### Report Time: Apr 30, 2020
### Report Content:
It seems the EKF2 and EKF3 are reporting the vehicle's position as being at the origin instead of the vehicle's last known position if the GPS is disabled.  To recreate this in SITL do the following with either EKF2 or EKF3 enabled:  
- arm the vehicle and takeoff in Guided  
- fly 50m North (or whatever)  
- param set GPS_TYPE 0  
- wait 5 seconds or so and the vehicle's reported position will jump back to the origin  
I thought we had fixed this as part of PR \\\#14184 but perhaps that was only if external navigation is used.  
At this point I'm also not sure if the issue is with the EKF or the vehicle code.
