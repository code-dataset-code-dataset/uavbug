### Title: Copter: Emergency Stop is not disarming motors
### Issue status: Closed
### Author: rmackay9
### Issue open time: Apr 12, 2019
# Report
### Report author: rmackay9
### Report Time: Apr 12, 2019
### Report Content:
When the user uses the Emergency Stop feature (attached to an auxiliary switch) the motors stop immediately but then after a few seconds (perhaps 10sec?) the vehicle disarms.  The intention of this delay is to allow a vehicle to recover from an accidental Emergency Stop but if it continues for too long, the vehicle is disarmed for safety.  
In Copter-3.6 (and lower) this feature works but it seems to be broken in Copter-3.7 (which hasn't been released yet)  
Method to recreate the problem in SITL:  
- run sim_vehicle for a quadcopter  
- set RC9_OPTION = 31 (for emergency stop)  
- switch to Loiter mode, arm and takeoff to 3m  
- "rc 9 2000" to invoke emergency stop  
In Copter-3.6 the vehicle will disarm at about 10 sec, in master/Copter-3.7 the vehicle will not disarm
