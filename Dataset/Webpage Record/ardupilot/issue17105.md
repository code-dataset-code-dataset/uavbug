Issue details  
\\\#17104 contains an autotest which is currently failing - the EKF forces a second EKF failsafe where it probably should not, instead doing a position-reset or similar.  
The issue can be reproduced in SITL by doing the following:  
- Start SITL running Copter (e.g. cd ArduCopter; ../Tools/autotest/sim_vehicle.py --map --console)  
- Guided (to switch the vehicle to Guided mode)  
- arm throttle (to arm vehicle)  
- takeoff 10 (to takeoff to 10m)  
- param set GPS_TYPE 0 (to disable the GPS)  
- wait 30 seconds as the vehicle enters Land mode and lands  
- param set GPS_TYPE 2 (to re-enable the GPS)  
- Guided  
- arm throttle <-- this fails because EKF has lost its position estimate
