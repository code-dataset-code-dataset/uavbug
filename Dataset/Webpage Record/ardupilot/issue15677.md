### Report author: rmackay9

### Report Content:
For some reason there is a change in behaviour of pivot turns if OA_TYPE = 1 (i.e. bendy ruler object avoidance is enabled).  
The issue is visible in SITL:  
- start a skid steering rover using ../Tools/autotest/sim_vehicle --map --console -f rover-skid  
- GUIDED (to switch the vehicle to Guided mode)  
- arm throttle  
- right-mouse-button click on the map at a point about 90 degrees off from the vehicle's heading  
If OA_TYPE = 0 the vehicle will rotate on the spot and then head towards the target.  If OA_TYPE = 1 the vehicle will driver forward and then turn towards the target.
