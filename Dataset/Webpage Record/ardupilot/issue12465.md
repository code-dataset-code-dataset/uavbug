# Report
### Report author: rmackay9
### Report Time: Oct 02, 2019
### Report Content:
We have had one report of a loophole in the ESC calibration procedure which can lead to the motors spinning up if the normal procedure isn't followed.  To recreate the motor spin-up issue do this:  
1. plug in a battery  
2. connect and set ESC_CALIBRATION = 3 to indicate the "auto" esc calibration should be performed (the MP makes this convenient with a button on the Initial Setup / Mandatory Hardware / ESC Calibration screen  
3. reboot the flight controller from the GCS (i.e. leave the battery plugged in).  This can be most easily done from MP's Action tab by setting the top-left drop-down to "PREFLIGHT_REBOOT_SHUTDOWN" and then push the "Do Action" button  
4. because the battery was not disconnected the ESCs will already be initialised so when the flight controller reboots and starts outputting high PWM values are part of the ESC calibration the motors will start.  
The solution is to somehow modify the GCS_MAVLINK::handle_preflight_reboot() function so that it refuses reboot if the ESC_CALIBRATION parameter has been set to 3.  This should force the user to reboot the flight controller by disconnecting the battery.  Note that when we refuse to reboot we should also provide a text message to the GCS to alert the user why we've refused to reboot.
