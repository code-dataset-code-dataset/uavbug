### Report Content:
I am unsure if these are Mission Planner issues or flight code issues so I am documenting them both here and in the MP issues list: ArduPilot/MissionPlanner\\\#2413  
All of these issues can be reproduced by doing the following:  
- Open Mission Planner  
- Open the Simulation page  
- Ensure the "wipe" checkbox is checked  
- Press the Copter icon at the bottom  
- Open Config, MAVFtp  
When trying to upload a Lua script to a copter in MP's simulator I've run into these problems:  
- Click, "@RomfS", then click on the unnamed (top directory?), 5 second delay before the directory listing is displayed.  5sec is not very long but it is very noticeably longer than if I click on one of the sub directories (i.e. logs) and then switch back to the top directory    
- Attempting to create a directory with the same name as an existing directory causes MP to lock-up for 30 seconds.  The directory is not created and no error message is displayed  
- Attempting to delete an empty directory causes MP to lock-up for 30 seconds.  A "Failed to delete file" message is displayed and the directory is not deleted  
- Attempting to create the scripts directory under @RomfS causes MP to lock-up for 30 seconds, the directory is not created and no error message is displayed
