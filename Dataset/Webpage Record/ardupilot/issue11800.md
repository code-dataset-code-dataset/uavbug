It seems like master TradHeli can produce a blank "PreArm:" message.  To recreate the issue:  
- load latest TradHeli firmware  
- clear all parameter and reboot the vehicle  
If using MP, check the messages window and you should see something like this.  Note how the 3rd line down has no message

EKF2 IMU1 forced reset
