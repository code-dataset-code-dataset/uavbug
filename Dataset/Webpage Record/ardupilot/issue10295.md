### Report Content:
Bug report  
ArduCopter autotests for octa-quad-frame fail  
The cause seams to be that ATC_RAT_RLL_D is set to 0, making the pre-arm checks fail:    
APM: PreArm: Check PIDs - ATC_RAT_RLL_D  
that has to be a bug because the octa-quad parameter file sets that one to 0.022 and the SITL gets that message:    
changed ATC_RAT_RLL_D from 0.003600 to 0.002220  
to reproduce this issue:  
cd arducopter    
./Tools/autotest/autotest.py build.ArduCopter defaults.ArduCopter fly.ArduCopter --frame octa-quad
