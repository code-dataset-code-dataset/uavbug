# Report
### Report author: magicrub
### Report Time: Aug 21, 2019
### Report Content:
Tested on cube black.  
1. Unplug USB  
2. Use telem 1 to send MAVLink command to reboot and stay in bootloader (just use uploader.py like usual but on a serial port)  
3. Bootloader hangs until USB power (data or no data) is applied.  
4. Once USB power is applied, and the bootloader finishes booting, you can optionally remove USB power.  
5. Continue with normal firmware update via telem 1.  
Side note, telem2 is not working at all which is a shame because that's the better one to connect to a companion computer because it's not high power.  
Expected behavior is that serial bootloading works while USB disconnected and on telem 1 and telem 2.
