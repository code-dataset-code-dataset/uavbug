# Report
### Report author: rmackay9
### Report Time: Jun 30, 2019
### Report Content:
The Polygon_intersects() function does not handle unclosed polygons (unlike Polygon_outside).  
This issue can be seen after this PR is merged to master.  To recreate the issue try this:  
- start SITL using Rover  
- create a small triangular polygon fence  
- enable Dijkstra's avoidance (OA_TYPE = 2) and reboot  
- switch to Guided mode and set a target position outside the polygon.  
- arm the vehicle  
- Repeat this with targets that cross each of the fence lines. You should see that if the line from the vehicle to the target position crosses the last line of the polygon fence, the vehicle will attempt to drive through the fence (it will be stopped by the lower level speed limiting avoidance code but this is still not great because the vehicle has wasted a lot of time driving towards a goal that it should know it can never reach).
